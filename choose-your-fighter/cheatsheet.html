THE MAPPING FORMULA
We use a XOR-based linear map over GF(2) to compute a 4-bit type index from 10 binary answers. Since the map has rank 4, the kernel has dimension 6, guaranteeing exactly 26 = 64 answer patterns per type. This is mathematically provable, not empirical.
// 10 yes/no answers → 4-bit type index (0-15)
bit0 = Q1 XOR Q5 XOR Q9
bit1 = Q2 XOR Q6 XOR Q10
bit2 = Q3 XOR Q7
bit3 = Q4 XOR Q8

type_index = (bit3 << 3) | (bit2 << 2) | (bit1 << 1) | bit0
